# Let AI Blog About AI

> *"Can an AI model write a meaningful article about itself?"*
>
> This project puts that question to the test, blending generative AI, prompt design, and real-world publishing.

## Overview

This is the project I built for the [Kaggle competition](https://www.kaggle.com/competitions/gen-ai-intensive-course-capstone-2025q1) concluding the [5-day Gen AI Intensive Course with Google](https://rsvp.withgoogle.com/events/google-generative-ai-intensive_2025q1). It explores **automated content creation using Generative AI**, where the model is both the subject and the author. Using Google’s **Gemini API**, I guided the model to generate a blog post reflecting on the project itself.

I did so by leveraging the following Gen AI techniques and capabilities:
- Prompt engineering.
- Document understanding.
- Grounding.
- Automated evaluation.

The entire workflow is available in the notebook, while the generated blog post has been published for a real-world audience on Medium. See it live here: [Medium blog post](https://gioconti.medium.com/automating-content-creation-let-ai-blog-about-ai-c567186c5fa3).
